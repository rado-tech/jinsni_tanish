# Lessons (Uzbek)

This project was built as a step-by-step tutorial. These files are the original
lesson material in Uzbek: theory first, then an exercise with `TODO` markers,
then a review of the result.

They are kept for reference and describe an earlier layout — the scripts have
since been renumbered and refactored into the `genderid` package. The concepts,
the reasoning behind each design choice, and the pitfalls encountered are still
accurate.

| Lesson | Topic |
|---|---|
| [DARS-01](DARS-01.md) | Digital audio basics, dataset exploration |
| [DARS-02](DARS-02.md) | Quality filtering, per-speaker caps, speaker-disjoint splits |
| [DARS-03](DARS-03.md) | STFT, mel scale, decibels, feature caching |
| [DARS-04](DARS-04.md) | CNN architecture and the training loop |
| [DARS-05](DARS-05.md) | Transfer learning, layer freezing, mixed precision |
| [DARS-06](DARS-06.md) | Test-set discipline, McNemar's test, slice analysis |
| [DARS-07](DARS-07.md) | VAD, sliding windows, confidence thresholds |
| [DARS-08](DARS-08.md) | Deployment, parity verification, dependency trimming |

# Darslar (o'zbekcha)

Bu loyiha bosqichma-bosqich dars sifatida qurilgan. Fayllar asl dars
materiallari: avval nazariya, keyin `TODO` bilan topshiriq, keyin natijani
tekshirish.

Ular eski tuzilmani tasvirlaydi — skriptlar keyinchalik qayta raqamlangan va
`genderid` paketiga birlashtirilgan. Lekin tushunchalar, har bir qarorning
sababi va yo'l-yo'lakay uchragan tuzoqlar hamon o'z kuchida.
